### 验收清单

| ID | 类型 | 验收项 | 验证方式 | 证据 | 结论 |
|---|---|---|---|---|---|
| AC-1 | 功能 | 登录后进入首页 | E2E 脚本步骤 1-3 | 截图 + 日志 | 待验 |
| AC-2 | 功能 | 用户名重复时给出明确提示 | 用例 + 截图 | test 名 + png | 待验 |
| AC-3 | 边界 | 空列表显示空态 | 用例 + 截图 | test 名 + png | 待验 |
| AC-4 | 边界 | 超长输入被拒绝且有提示 | 用例 | test 名 | 待验 |
| AC-5 | 集成 | 刷新后状态不丢 | 手工/脚本 | 录屏或 png | 待验 |
| AC-6 | 集成 | 前后端字段一致 | 抓包/断言 | 请求响应片段 | 待验 |
| AC-7 | 卫生 | 本次改动无 TODO/console.log | 扫描命令 | diff 输出 | 待验 |
| AC-8 | 卫生 | 无调试残留与占位实现 | 扫描 + 目视 | diff 输出 | 待验 |

规则：

- **功能 / 边界 / 集成 / 卫生每类至少一条**。
- 结论只能是：通过 / 不通过 / 未验证（附原因）。
- 每条必须绑定「可执行的验证方式 + 可引用的证据路径」。
- 计划中的每个 task 必须映射到这里的 ID（`验收映射：AC-1、AC-5`）。
